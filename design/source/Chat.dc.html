Debounce in the router

Auto · mostly Balanced

How should I debounce duplicate requests hitting the router within the same second?

balanced · llama-3.3-70b · Groq · 412 ms

Key each request by a hash of its tier and normalized prompt, and keep in-flight requests in a map. A duplicate that arrives while the first is running awaits the same promise instead of calling the provider again.

const inflight = new Map();

export function dedupe(key, run) {
  if (inflight.has(key)) return inflight.get(key);
  const p = run().finally(() => inflight.delete(key));
  inflight.set(key, p);
  return p;
}

Would this still work across multiple Workers instances?

Thinking balanced · llama-3.3-70b
balanced · llama-3.3-70b · Groq · 978 ms

Not as written: the map lives inside one isolate, so two instances never see each other's requests. Move the in-flight key into a Durable Object named by the hash. Every duplicate then lands in the same object and shares one upstream call.
