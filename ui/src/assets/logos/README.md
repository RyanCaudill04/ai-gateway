# Provider and model logos

These SVGs are copied unchanged from
[lobe-icons](https://github.com/lobehub/lobe-icons) (`@lobehub/icons-static-svg`
1.102.0, MIT licensed). `gemini`, `meta`, `gemma`, and `deepseek` are the set's
colour versions; `groq`, `ollama`, and `openrouter` are single-colour and take
the page's text colour.

The logos are trademarks of their owners and are used here only to identify
each provider and model.

To add one, copy its SVG here and register it in `src/logos.ts`.
